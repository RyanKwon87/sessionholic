설정

화면

화면 모드

자동은 기기의 화면 모드를 따릅니다. 터미널은 항상 어두운 화면으로 보입니다.

글자 크기

보드의 글자 크기입니다. 터미널 글자 크기는 터미널 설정에서 따로 바꿉니다. 이 선택들은 이 브라우저에만 저장됩니다.

초안 복원

새로고침·탭 닫기 뒤 복원합니다. 잠그거나 로그인이 만료되면 삭제합니다.

대화 보존·정리

종료된 세션의 전체 텍스트 대화와 발췌 요약을 보존합니다. 사진·영상·첨부 파일은 포함하지 않으며 작업 파일은 그대로 둡니다.

맥 기기의 대화를 보존합니다. Codex의 확인된 원본 기록만 자동 정리하며, Claude 원본과 Windows 기록은 유지합니다.

빠른 답장

대화 입력창의 도구 › 빠른 답장에 보일 문구입니다. 한 줄에 하나씩, 12개까지 적습니다. 선택하면 문구를 입력창에 넣고 바로 보냅니다. 작성 중인 내용과 첨부도 함께 보냅니다. 저장한 문구는 이 보드의 모든 기기에서 공유합니다.

저장 프롬프트

빠른 답장 목록의 문구 아래에 제목으로 보이는 긴 프롬프트입니다. 항목마다 "## 제목" 줄을 적고 그 아래 줄부터 본문을 적습니다(빈 줄을 포함한 여러 줄, 본문 4,000자, 20개까지). 선택하면 입력창에 넣고 바로 보내며, 제목 끝에 [입력창]을 붙인 항목은 보내지 않고 입력창에만 넣습니다. 본문의 줄은 "## "로 시작할 수 없습니다. 저장한 프롬프트는 이 보드의 모든 기기에서 공유합니다.
